# System Card Versions

These files document the three main behavioral stages of the letter agent.

- [`v1-baseline-drafter.md`](v1-baseline-drafter.md): simple letter generation without factual safeguards.
- [`v2-factual-clarification.md`](v2-factual-clarification.md): missing-fact questions and visible placeholders.
- [`v3-confirm-before-drafting.md`](v3-confirm-before-drafting.md): confirmation, factual authority, and non-guessing revision behavior.

## Provenance note

V1 and V2 are reconstructions from saved interface evidence and the prompts recorded during development. They are not presented as verbatim exports of a single historical system prompt. V3 documents the current behavioral contract implemented across the API routes and interface components.
